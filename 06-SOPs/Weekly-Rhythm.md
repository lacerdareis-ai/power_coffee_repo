# Weekly Rhythm SOP — Power Coffee Sales Motor

> This is your operating system. Follow this rhythm every week. The AI does 80% of the work. You direct, review, and decide.

---

## Daily Non-Negotiables (15 min/day)

- [ ] Check HE-OS alerts (Telegram) for any competitor moves or anomalies
- [ ] Glance at Meta Ads Manager — any ad spending without results? Pause it
- [ ] Check Shopify for new orders and customer messages
- [ ] Capture any ideas or insights in Obsidian (04-Analytics or 02-Campaigns)

---

## Monday — Analyze + Plan (2 hours)

### Morning Block (1 hour): Weekly Review
1. Open Meta Ads Manager → Export last 7 days data
2. Paste into Claude using **Prompt 04 (Weekly Performance Analyst)**
3. Claude generates your weekly report with winners, losers, and recommendations
4. Save report in `04-Analytics/Week-[X]-Report.md`
5. Update the winning patterns log: `04-Analytics/Winning-Patterns.md`

### Afternoon Block (1 hour): Plan the Week
1. Based on Claude's recommendations, decide:
   - Which ads to kill
   - Which angles to double down on
   - What new creatives to produce
2. Write this week's creative brief in `02-Campaigns/Week-[X]-Plan.md`
3. Update content calendar with posting schedule

### Monday Deliverable:
- [ ] Weekly report saved in Obsidian
- [ ] Losing ads paused in Meta
- [ ] Budget reallocated to winners
- [ ] This week's creative plan written

---

## Tuesday — Create Ads (2 hours)

### Morning Block (1 hour): Copy
1. Open Claude with **Prompt 01 (Ad Copy Generator)**
2. Generate 5-8 new ad copy variations based on Monday's plan
3. Use winning angles from last week as starting points
4. Save all variations in `02-Campaigns/Ad-Copy-Bank.md`

### Afternoon Block (1 hour): Visuals
1. Open Higgsfield Pro
2. Use prompts from `03-Creatives/Higgsfield-Prompt-Library.md`
3. Generate matching images and videos for each ad copy
4. Download and organize by angle name
5. Save the prompts that worked best back into the library

### Tuesday Deliverable:
- [ ] 5-8 new ad copy variations written
- [ ] Matching images/videos generated in Higgsfield
- [ ] All assets saved and organized

---

## Wednesday — Launch + Email (1.5 hours)

### Morning Block (1 hour): Ad Launch
1. Upload new creatives to Meta Ads Manager
2. Create new ads within existing winning ad sets
3. Set up any A/B tests (one variable at a time: copy OR image, never both)
4. Double-check targeting and budget allocation
5. Activate new ads

### Afternoon Block (30 min): Email
1. Check email sequence performance (open rates, click rates)
2. If any email underperforms (<15% open rate), use Claude to rewrite subject line
3. Draft any one-off broadcast emails (new product, sale, content piece)
4. Schedule in Shopify Email or Klaviyo

### Wednesday Deliverable:
- [ ] New ads live in Meta
- [ ] A/B tests running
- [ ] Email sequences reviewed and updated

---

## Thursday — Content + Social (1.5 hours)

### Morning Block (1 hour): Content Creation
1. Open Claude with **Prompt 05 (Social Content Creator)**
2. Generate 3-4 IG posts for the week
3. Open Higgsfield to create matching visuals
4. Write reel scripts word-for-word (for filming or AI generation)

### Afternoon Block (30 min): Schedule + Engage
1. Schedule posts in Meta Business Suite
2. Reply to any comments or DMs from this week
3. Engage with 5-10 relevant accounts (comment on their posts — build community)

### Thursday Deliverable:
- [ ] 3-4 IG posts created and scheduled
- [ ] Reel scripts written
- [ ] Community engagement done

---

## Friday — Optimize (1 hour)

### Single Block:
1. Mid-week ad performance check in Meta Ads Manager
2. Kill any new ads that are clearly underperforming (CPA > $30 after $20 spent)
3. Increase budget 10-20% on any ad with CPA < $12 and 3+ days of data
4. Check HE-OS for any competitor intelligence this week
5. Quick scan of Amazon reviews for competitors (new complaints = new ad angles)
6. Update Obsidian vault:
   - `04-Analytics/Winning-Patterns.md` with any new insights
   - `01-Prompts/` if any prompt needs refinement
   - `03-Creatives/` if any Higgsfield prompt worked exceptionally well

### Friday Deliverable:
- [ ] Underperforming ads killed
- [ ] Winners scaled
- [ ] Obsidian vault updated with this week's learnings
- [ ] Brain is ready to rest

---

## Saturday/Sunday — Rest + Capture

- HE-OS monitors automatically (competitor alerts, social mentions)
- If you have a random idea, open Obsidian on your phone and drop it in `02-Campaigns/Ideas-Inbox.md`
- No active work. Family time. Church. Recharge.
- The system works because you rest. Burnout kills consistency.

## Monthly Milestones

### Month 1: Foundation
- [ ] All email sequences live (welcome, abandoned cart, post-purchase)
- [ ] 12+ ad variations tested
- [ ] First sales data collected
- [ ] Baseline CPA and ROAS established

### Month 2: Optimization
- [ ] Winning angles identified (top 3)
- [ ] Budget scaled to $15-20/day on winners
- [ ] Lookalike audience created (if 25+ purchases)
- [ ] First reorder emails sent
- [ ] Obsidian vault has 4+ weekly reports showing trends

### Month 3: Growth Decision
- [ ] Consistent ROAS > 2.0x on winning campaigns
- [ ] Monthly revenue trending upward
- [ ] Decision point: Is it time for Phase 1 (2 Mac Minis)?
- [ ] If revenue > $3K/month → green light Phase 1
- [ ] If revenue < $1K/month → pivot angles, test new audiences, refine product

## HE-OS Daily Tasks (runs automatically)

Configure these in Hermes after setup:

1. **Morning brief (7am):** Send daily Telegram summary of yesterday's ad spend, purchases, and any anomalies
2. **Competitor watch (daily):** Check competitor IG accounts for new posts, check their Amazon listings for price changes
3. **Review monitor (daily):** Alert if any new 1-star reviews appear on competitors' Amazon listings (= ad angle opportunities)
4. **Inventory alert:** Notify when Shopify inventory drops below 20 units
