## LINKEDIN
### Post
Almost 500 new email addresses landed in one afternoon. Adding them was the easy call. Knowing which two not to was the one that mattered.

Growing the list felt like a pure win. It almost wasn't.

We run our weekly newsletter off one flat file — every address in it, one email, every Saturday. No segmentation, no per-send review step. Simple on purpose. Also unforgiving: there's no safety net between editing that file and real mail landing in real inboxes a few days later.

So when a list of roughly 490 new addresses showed up — some named local-business contacts I'd actually met, a much bigger batch of unnamed personal Gmail addresses from somewhere else — the instinct was obvious. More addresses. Add them. The list grows.

Here's the part that's easy to skip in that moment: deliverability isn't scored per-address. It's scored in aggregate, by every major inbox provider, against your whole sending domain at once. Mass-adding people who never opted in doesn't just risk those 490 new addresses bouncing or getting marked spam — it risks the inbox placement of the other eight thousand real subscribers who actually signed up, because the whole list shares one sender reputation. A newsletter that's been landing in inboxes for months can start landing in spam folders because of a batch you added last week, for everyone, not just the new names.

"Grow the list" feels like it only has an upside. It doesn't, if a meaningful slice of what you're adding doesn't actually want the email.

We flagged it before touching anything — not as a formality, as an actual "are you sure, here's the real mechanism" conversation. The answer was yes: real contacts, not a scraped list, add them. So we did. All but two. And those two weren't even a judgment call — one address was an automated bounce handler, not a person; the other was a different company's own unsubscribe address, a routing mistake rather than a contact. Everything else, 488 addresses, went in clean.

List's at 8,498 now. Bigger, and still real.

What actually changed afterward: "should we grow the list" and "is it safe to add this batch right now" used to be one decision. They're two, every time, from here on. Conflating them is exactly how a list that's been growing cleanly for months quietly turns into one that can't reliably reach anyone.

The lesson isn't "don't grow your list." It's that growth and reputation pull in different directions more often than the first instinct admits — and the moment to notice that is before you hit save on the file, not after the next Saturday's open rate drops and you're trying to figure out why.

— Leo, building Power Coffee one real decision at a time.

## SCIENCE NOTE — Founder Interview Prep (not for publishing)
**Ingredient / mechanism:** Taurine — osmolytic and cytoprotective modulation under metabolic demand

Taurine (2-aminoethanesulfonic acid), present at 2.1g per serving in Power Coffee, functions primarily as an organic osmolyte in excitable tissues including neurons and cardiomyocytes. Under conditions of metabolic stress — such as sustained cognitive load or physical exertion — intracellular taurine concentrations help regulate cell volume and stabilize membrane potential by modulating chloride channel conductance, particularly through the glycine receptor family. This is distinct from stimulant activity: taurine does not drive arousal through monoamine pathways. Instead, it buffers the cellular environment against the oxidative byproducts of high metabolic demand, supporting mitochondrial membrane integrity and attenuating reactive oxygen species accumulation. In the context of caffeine co-administration, this cytoprotective role may help sustain neural efficiency during the extended arousal window caffeine creates, rather than amplifying the peak spike. The 2.1g dose in Power Coffee aligns with ranges used in controlled exercise-performance studies examining taurine's ergogenic and neuroprotective effects.

**Reference:** Schaffer SW, Ju Jong C, Kc R, Azuma J. Physiological roles of taurine in heart and muscle. J Biomed Sci. 2010;17(Suppl 1):S2. PMID: 20804598 [VERIFY CITATION for full applicability to cognitive context]

**Interview angle:** Taurine at this dose may support the cellular stability that helps clean caffeine energy last — it is not a stimulant, it is more like insulation for the system running the stimulant.

const W = 1080;
const H = 1920;
const GAP = 60;

// ── HELPERS ──────────────────────────────────────────────────
function addRect(parent, x, y, w, h, color, opacity) {
  if (opacity === undefined) { opacity = 1; }
  var r = figma.createRectangle();
  r.x = x; r.y = y; r.resize(w, h);
  r.fills = [{ type: "SOLID", color: col(color), opacity: opacity }];
  parent.appendChild(r);
  return r;
}

// Font map — matches make_carousel.py (Pillow) rendering
// Headlines/body → Georgia | Labels/pills/footer → Arial
function _fontFor(weight) {
  if (weight === "Black Italic" || weight === "Bold Italic") { return { family: "Georgia", style: "Bold Italic" }; }
  if (weight === "Black" || weight === "Bold" && false)      { return { family: "Georgia", style: "Bold" }; }
  if (weight === "Italic" || weight === "Regular Italic")    { return { family: "Georgia", style: "Italic" }; }
  // Labels, overlines, pills, footer, counter use Arial
  if (weight === "Bold")    { return { family: "Arial", style: "Bold" }; }
  if (weight === "Regular") { return { family: "Georgia", style: "Regular" }; }
  return { family: "Arial", style: weight };
}

async function addText(parent, txt, x, y, w, size, weight, color, align, lineH) {
  if (align === undefined) { align = "LEFT"; }
  if (lineH === undefined) { lineH = 1.05; }
  var fn = _fontFor(weight);
  await figma.loadFontAsync(fn);
  var t = figma.createText();
  t.fontName = fn;
  t.characters = txt;
  t.fontSize = size;
  t.textAlignHorizontal = align;
  t.fills = [{ type: "SOLID", color: col(color) }];
  t.lineHeight = { unit: "PERCENT", value: lineH * 100 };
  t.x = x; t.y = y;
  t.resize(w, t.height);
  parent.appendChild(t);
  return t;
}

async function buildSlide(data, offsetX) {
  var frame = figma.createFrame();
  frame.name = "Slide " + data.id + " - " + data.slideType;
  frame.resize(W, H);
  frame.x = offsetX; frame.y = 0;
  frame.fills = [{ type: "SOLID", color: col(data.bg) }];
  frame.clipsContent = true;

  for (var i = 0; i < 12; i++) {
    var line = figma.createLine();
    line.x = -100 + i * 110; line.y = 0;
    line.resize(H * 1.5, 0);
    line.rotation = -55;
    line.strokes = [{ type: "SOLID", color: col(data.accent), opacity: 0.04 }];
    line.strokeWeight = 40;
    frame.appendChild(line);
  }

  await addText(frame, "0" + data.id, 64, 60, 120, 13, "Bold", "WHITE");
  addRect(frame, 64, 85, 20, 2, data.accent);

  if (data.overline) {
    await addText(frame, data.overline, 64, 96, W - 128, 12, "Bold", "BROWN_L", "LEFT", 1.4);
  }

  if (data.pivotBar) { addRect(frame, 64, 148, 6, 260, data.accent); }

  var hX; if (data.pivotBar) { hX = 90; } else { hX = 64; }
  var hlColor; if (data.isCTA) { hlColor = "WHITE"; } else { hlColor = data.textColor; }
  await addText(frame, data.headline, hX, 148, W - hX - 40, 128, "Black Italic", hlColor, "LEFT", 0.92);

  var divY; if (data.isCTA) { divY = 740; } else { divY = 730; }
  addRect(frame, 64, divY, W - 128, 2, data.accent, 0.6);

  if (data.pills) {
    var pillX = 64;
    for (var j = 0; j < data.pills.length; j++) {
      var pill = data.pills[j];
      await figma.loadFontAsync({ family: "Arial", style: "Bold" });
      var pf = figma.createFrame();
      pf.resize(160, 36); pf.x = pillX; pf.y = divY + 20;
      pf.fills = [{ type: "SOLID", color: col("BROWN"), opacity: 0.25 }];
      pf.cornerRadius = 0;
      frame.appendChild(pf);
      var pt = figma.createText();
      pt.fontName = { family: "Arial", style: "Bold" };
      pt.characters = pill; pt.fontSize = 10;
      pt.textAlignHorizontal = "CENTER";
      pt.fills = [{ type: "SOLID", color: col("CREAM") }];
      pt.letterSpacing = { unit: "PERCENT", value: 20 };
      pt.resize(160, 36); pt.x = 0; pt.y = 12;
      pf.appendChild(pt);
      pillX += 172;
    }
  }

  if (data.subtext) {
    var subY; if (data.pills) { subY = divY + 70; } else { subY = divY + 24; }
    await addText(frame, data.subtext, 64, subY, W - 128, 22, "Regular", { r: 0.85, g: 0.80, b: 0.72 }, "LEFT", 1.6);
  }

  addRect(frame, 64, H - 96, W - 128, 1, "BROWN_L", 0.3);
  await addText(frame, "THE POWER COFFEE", 64, H - 78, 400, 11, "Bold", "BROWN_L", "LEFT", 1.4);
  await addText(frame, "CLEAN ENERGY. REAL FOCUS.", W - 380, H - 78, 316, 10, "Regular", { r: 0.6, g: 0.55, b: 0.48 }, "RIGHT", 1.4);

  if (data.isCTA) {
    addRect(frame, 0, H - 180, W, 180, "BROWN");
    await addText(frame, "POWER COFFEE", 64, H - 138, W - 128, 14, "Black", "WHITE", "LEFT", 1.2);
    await addText(frame, "thepowercoffee.com", 64, H - 110, W - 128, 13, "Regular", { r: 1, g: 0.95, b: 0.88 }, "LEFT", 1.4);
    await addText(frame, "@POWERCOFFEE.OFC", 64, H - 76, W - 128, 12, "Bold", "WHITE", "LEFT", 1.4);
  }

  figma.currentPage.appendChild(frame);
  return frame;
}

async function main() {
  var frames = [];
  for (var i = 0; i < SLIDES.length; i++) {
    var frame = await buildSlide(SLIDES[i], i * (W + GAP));
    frames.push(frame);
  }
  figma.viewport.scrollAndZoomIntoView(frames);
  figma.notify("Power Coffee - slides created!", { timeout: 4000 });
}

main();
