### Body

## The Fourth Cup Problem

Most people who hit an energy wall at 3pm are not drinking too little coffee. They are drinking three or four cups and still losing the afternoon. If more caffeine were the answer, this would not be happening to so many people who already drink plenty of it.

The issue is not the quantity of caffeine. It is how caffeine works when it works alone.

## What Caffeine Actually Does

Caffeine does not create energy. It blocks a signal. Specifically, it blocks adenosine, the compound your brain accumulates over the course of the day to make you feel tired. When caffeine blocks that signal, you feel alert. But the adenosine keeps building underneath. When the caffeine clears, it floods back. That is the crash.

Each additional cup delays the flood by thirty to forty minutes. But it does not reset the underlying buildup. By the third or fourth cup, you are borrowing against a debt that keeps growing.

## What Fills the Gap

Certain ingredients support steady energy in a completely different way.

**Taurine** helps regulate the overstimulation response that comes with a fast caffeine spike, which is why energy drinks load up on it alongside their caffeine. The problem is they also pair it with sugar and very high caffeine doses that cancel the benefit.

**Matcha** contains its own caffeine alongside a compound that slows absorption. The result is energy that rises gradually and stays level rather than peaking and dropping. This is why green tea drinkers report a different quality of alertness compared to coffee drinkers.

**Thermogenic spices** like cinnamon support how efficiently your body processes and uses available energy, which helps prevent the mid-afternoon dip that hits hardest when blood sugar fluctuates.

## SCIENCE NOTE — Founder Interview Prep (not for publishing)
**Ingredient / mechanism:** Taurine as an osmoregulatory and excitatory-inhibitory modulator in high-stimulant contexts

Taurine (2-aminoethanesulfonic acid) is one of the most abundant free amino acids in the human brain, heart, and skeletal muscle. Unlike conventional amino acids, it is not incorporated into proteins; instead it functions as an osmolyte, regulating cellular volume under metabolic stress, and as a modulator of GABA-A and glycine receptors, two of the central inhibitory receptor systems. In high-stimulant contexts, this matters because caffeine-driven adenosine blockade simultaneously disinhibits dopamine and norepinephrine pathways, which can produce an overstimulation response, the jitteriness and anxious arousal associated with high caffeine intake. Taurine's agonism at GABA-A receptors provides a partial counterweight to this excitatory surge without sedating the user, which may explain the qualitative difference in alertness reported by people who combine taurine with caffeine versus caffeine alone. Power Coffee supplies 2.1g per serving, within the range studied in exercise performance and cardiovascular research.

**Reference:** Schaffer S, Kim HW. Effects and Mechanisms of Taurine as a Therapeutic Agent. Biomol Ther (Seoul). 2018;26(3):225-241. PMID: 29631391 [VERIFY CITATION — confirm PMID matches this exact paper before citing publicly]

**Interview angle:** Taurine may help modulate the overstimulation side of a caffeine response by supporting inhibitory receptor activity, which supports the case for pairing it with caffeine rather than using caffeine alone.

function addRect(parent, x, y, w, h, color, opacity) {
  if (opacity === undefined) { opacity = 1; }
  var r = figma.createRectangle();
  r.x = x; r.y = y; r.resize(w, h);
  r.fills = [{ type: "SOLID", color: col(color), opacity: opacity }];
  parent.appendChild(r);
  return r;
}

// Font map — matches make_carousel.py (Pillow) rendering
// Headlines/body → Georgia | Labels/pills/footer → Arial
function _fontFor(weight) {
  if (weight === "Black Italic" || weight === "Bold Italic") { return { family: "Georgia", style: "Bold Italic" }; }
  if (weight === "Black" || weight === "Bold" && false)      { return { family: "Georgia", style: "Bold" }; }
  if (weight === "Italic" || weight === "Regular Italic")    { return { family: "Georgia", style: "Italic" }; }
  // Labels, overlines, pills, footer, counter use Arial
  if (weight === "Bold")    { return { family: "Arial", style: "Bold" }; }
  if (weight === "Regular") { return { family: "Georgia", style: "Regular" }; }
  return { family: "Arial", style: weight };
}

async function addText(parent, txt, x, y, w, size, weight, color, align, lineH) {
  if (align === undefined) { align = "LEFT"; }
  if (lineH === undefined) { lineH = 1.05; }
  var fn = _fontFor(weight);
  await figma.loadFontAsync(fn);
  var t = figma.createText();
  t.fontName = fn;
  t.characters = txt;
  t.fontSize = size;
  t.textAlignHorizontal = align;
  t.fills = [{ type: "SOLID", color: col(color) }];
  t.lineHeight = { unit: "PERCENT", value: lineH * 100 };
  t.x = x; t.y = y;
  t.resize(w, t.height);
  parent.appendChild(t);
  return t;
}

async function buildSlide(data, offsetX) {
  var frame = figma.createFrame();
  frame.name = "Slide " + data.id + " - " + data.slideType;
  frame.resize(W, H);
  frame.x = offsetX; frame.y = 0;
  frame.fills = [{ type: "SOLID", color: col(data.bg) }];
  frame.clipsContent = true;

  for (var i = 0; i < 12; i++) {
    var line = figma.createLine();
    line.x = -100 + i * 110; line.y = 0;
    line.resize(H * 1.5, 0);
    line.rotation = -55;
    line.strokes = [{ type: "SOLID", color: col(data.accent), opacity: 0.04 }];
    line.strokeWeight = 40;

  var hX; if (data.pivotBar) { hX = 90; } else { hX = 64; }
  var hlColor; if (data.isCTA) { hlColor = "WHITE"; } else { hlColor = data.textColor; }
