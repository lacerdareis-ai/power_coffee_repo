### Body

## You Are Not Tired. Your Formula Is Wrong.

You drink one cup. You drink a second. By the time your third meeting starts, you are running on friction and willpower instead of actual energy.

This is one of the most common complaints among high-performing adults who drink good coffee and still cannot hold a productive morning. The problem is not the caffeine. The problem is that caffeine was never designed to work alone.

## What Caffeine Actually Does

Caffeine works by occupying adenosine receptors in your brain. Adenosine is the molecule that signals fatigue — it accumulates naturally while you are awake. Caffeine blocks that signal, which is why you feel alert shortly after drinking it.

But the adenosine does not stop building just because it is blocked. When the caffeine clears — usually 90 to 120 minutes after your cup — the accumulated adenosine rushes in. That is the crash. Not your constitution. Not the brand of coffee. The mechanism.

## What Taurine Does Differently

Taurine is an amino acid concentrated in the brain, heart, and skeletal muscle. It supports neuronal stability — meaning it helps calm the kind of overstimulation that pure caffeine can create. When taurine is present alongside caffeine, research suggests the combination may support a steadier, longer-lasting state of focus than caffeine achieves on its own.

This is why taurine appears in virtually every commercial energy drink. Most of those drinks pair it with excessive sugar and synthetic dyes. The taurine does its job. Everything around it undoes the benefit.

## The Combination That Changes the Morning

Power Coffee pairs approximately 175mg of natural caffeine with 2.1g of taurine per serving. The caffeine provides the lift. The taurine helps hold the floor steady underneath it. The result is energy that supports a full morning of focused work — without the hard stop at 10am.

One scoop into your existing cup. Nothing new to buy, brew, or time.

## SCIENCE NOTE — Founder Interview Prep (not for publishing)
**Ingredient / mechanism:** Taurine — osmolyte function and neuronal stability under stimulant load

Taurine (2-aminoethanesulfonic acid) is the most abundant free amino acid in mammalian brain tissue, where it functions primarily as an osmolyte and inhibitory neuromodulator. Unlike classical neurotransmitters, taurine does not bind to a single named receptor with high specificity; instead, it acts as a partial agonist at both GABA-A receptors and glycine receptors, gating chloride ion influx and reducing neuronal excitability. This is mechanistically distinct from caffeine's action as an adenosine A1/A2A receptor antagonist. Caffeine raises intraneuronal cAMP by blocking adenosine-mediated inhibition of adenylyl cyclase, which increases firing rate. Taurine's chloride-channel activity partially counteracts this excitatory pressure, supporting a state of alert calm rather than escalating arousal. Under conditions of high oxidative or osmotic stress — which acute caffeine loading can induce — taurine also functions as a cytoprotective buffer, reducing reactive oxygen species accumulation in neural tissue. The 2.1g dose in Power Coffee sits within the range studied in human trials on exercise performance and cognitive steadiness.

**Reference:** Schaffer SW, Ju Jong C, Kc R, Azuma J. Physiological roles of taurine in heart and muscle. J Biomed Sci. 2010;17(Suppl 1):S2. PMID: 20804579 [VERIFY CITATION for the specific neuronal excitability claim — the cytoprotective cardiac finding is well-documented; the GABA-A partial agonism finding is established in animal models and requires human-study cross-check before citing on air]

**Interview angle:** Taurine may support the kind of steady, calm focus that caffeine alone tends to erode — not by adding stimulation, but by modulating the excitatory pressure caffeine creates at the neuronal level.

function addRect(parent, x, y, w, h, color, opacity) {
  if (opacity === undefined) { opacity = 1; }
  var r = figma.createRectangle();
  r.x = x; r.y = y; r.resize(w, h);
  r.fills = [{ type: "SOLID", color: col(color), opacity: opacity }];

// Font map — matches make_carousel.py (Pillow) rendering
// Headlines/body → Georgia | Labels/pills/footer → Arial
function _fontFor(weight) {
  if (weight === "Black Italic" || weight === "Bold Italic") { return { family: "Georgia", style: "Bold Italic" }; }
  if (weight === "Black" || weight === "Bold" && false)      { return { family: "Georgia", style: "Bold" }; }
  if (weight === "Italic" || weight === "Regular Italic")    { return { family: "Georgia", style: "Italic" }; }
  // Labels, overlines, pills, footer, counter use Arial
  if (weight === "Bold")    { return { family: "Arial", style: "Bold" }; }
  if (weight === "Regular") { return { family: "Georgia", style: "Regular" }; }
  return { family: "Arial", style: weight };
}

async function addText(parent, txt, x, y, w, size, weight, color, align, lineH) {
  if (align === undefined) { align = "LEFT"; }
  if (lineH === undefined) { lineH = 1.05; }

  await figma.loadFontAsync(fn);
  var t = figma.createText();
  t.fontName = fn;
  t.characters = txt;
  t.fontSize = size;
  t.textAlignHorizontal = align;
  t.fills = [{ type: "SOLID", color: col(color) }];
  t.lineHeight = { unit: "PERCENT", value: lineH * 100 };
  t.x = x; t.y = y;
  t.resize(w, t.height);
  parent.appendChild(t);
  return t;
}
