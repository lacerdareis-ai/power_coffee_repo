## The Supplement Aisle Has a Trust Problem

If you have ever picked up a supplement, read a promise on the label, and quietly wondered whether any of it was real — that instinct is doing its job.

The functional supplement space is full of products that lead with bold claims and bury the evidence, or skip it entirely. Proprietary blends, vague dosages, and phrases designed to sound scientific without being accountable to anything.

Skepticism is not a barrier to buying. It is a reasonable response to a category that has not always told the truth.

## What Independent Certification Actually Means

Third-party certification means an independent laboratory tests the product outside the brand's control and confirms that what is on the label matches what is in the product — ingredient by ingredient, at the declared levels.

It is not a marketing badge. It is accountability made visible.

For Power Coffee, certification meant submitting the formula — Natural Caffeine, Taurine, Ginkgo Biloba Extract, and the full blend — to an external review process and accepting whatever the results showed. That is a different standard than a brand simply stating that their product is clean.

## An MD Review Adds a Second Layer

Beyond laboratory testing, the formula was reviewed by an MD. This is not a celebrity endorsement. It is a clinical lens applied to ingredient interactions, dosage levels, and safety profile — the kind of review that surfaces questions the label alone cannot answer.

Combined with third-party panel certification, the result is a product you can interrogate. Read the label. Cross-reference the amounts. Ask your doctor about any ingredient. The numbers are real and they are available.

## The 30-Day Guarantee Is the Third Layer

Certification tells you the product is what it says it is. The 30-day guarantee tells you that if steady energy, no afternoon crash, and a cleaner morning routine are not your experience — you are not stuck with the purchase.

These three things together — certification, MD review, and the guarantee — are designed for the person who wants to try something and needs to know the risk is low before they do.

## SCIENCE NOTE — Founder Interview Prep (not for publishing)
**Ingredient / mechanism:** Ginkgo Biloba Extract — Platelet-Activating Factor antagonism and microvascular tone

Power Coffee's certified panel includes 207mg of Ginkgo Biloba Extract per 10g serving — a standardized extract delivering flavonoid glycosides and terpene lactones (ginkgolides and bilobalide) as the pharmacologically active fractions.

The terpene lactones, specifically ginkgolide B, function as selective antagonists of Platelet-Activating Factor (PAF), a phospholipid mediator involved in platelet aggregation and inflammatory signaling at the vessel wall. By antagonizing PAF receptors, ginkgolide B supports vasodilatory tone in small cerebral vessels without acting as a direct stimulant — a mechanistically distinct pathway from caffeine's adenosine antagonism.

The flavonoid glycosides contribute antioxidant activity at the mitochondrial and vascular endothelial level, reducing reactive oxygen species that would otherwise impair nitric oxide bioavailability. The net effect across both fractions is support for cerebral microvascular circulation and neuronal oxygen delivery — which maps to the experienced outcome of clearer, more sustained cognitive availability rather than a stimulant spike.

At 207mg, the dose sits within the range studied in cognitive maintenance research in healthy adults.

**Reference:** DeFeudis FV, Drieu K. "Ginkgo biloba extract (EGb 761) and CNS functions: basic studies and clinical applications." Curr Drug Targets. 2000;1(1):25-58. [VERIFY CITATION for exact volume details]

**Interview angle:** Ginkgo's mechanism is not stimulant-based — it may support the microvascular environment in which the brain does its work, which is a different lever than simply adding more caffeine.

// BRAND COLORS - use quoted string keys in SLIDES data
const COLORS = {
  BLACK:   { r: 0.07, g: 0.06, b: 0.05 },
  BROWN:   { r: 0.48, g: 0.24, b: 0.12 },
  BROWN_L: { r: 0.75, g: 0.48, b: 0.28 },
  CREAM:   { r: 0.94, g: 0.91, b: 0.84 },
  WHITE:   { r: 1,    g: 1,    b: 1    },
  DARK_BG: { r: 0.10, g: 0.09, b: 0.08 },
};
function col(name) { return COLORS[name] || name; }

const W = 1080;
const H = 1920;
const GAP = 60;

// SLIDE DATA - accent/bg/textColor must be quoted strings: "BLACK", "BROWN", "BROWN_L", "CREAM", "WHITE"
const SLIDES = [{ id: 1, slideType: "hook", overline: "REAL BUYER. REAL RESULTS.", headline: "DAY 1 SKEPTIC.\nDAY 7\nSTEADY.", subtext: "A real buyer's words  -  before and after.", accent: "BROWN", bg: "BLACK", textColor: "CREAM" }
];

// ── HELPERS ──────────────────────────────────────────────────
function addRect(parent, x, y, w, h, color, opacity) {
  if (opacity === undefined) { opacity = 1; }
  var r = figma.createRectangle();
  r.x = x; r.y = y; r.resize(w, h);
  r.fills = [{ type: "SOLID", color: col(color), opacity: opacity }];
  parent.appendChild(r);
  return r;
}

// Font map — matches make_carousel.py (Pillow) rendering
// Headlines/body → Georgia | Labels/pills/footer → Arial
function _fontFor(weight) {
  if (weight === "Black Italic" || weight === "Bold Italic") { return { family: "Georgia", style: "Bold Italic" }; }
  if (weight === "Black" || weight === "Bold" && false)      { return { family: "Georgia", style: "Bold" }; }
  if (weight === "Italic" || weight === "Regular Italic")    { return { family: "Georgia", style: "Italic" }; }
  // Labels, overlines, pills, footer, counter use Arial
  if (weight === "Bold")    { return { family: "Arial", style: "Bold" }; }
  if (weight === "Regular") { return { family: "Georgia", style: "Regular" }; }
  return { family: "Arial", style: weight };
}

async function addText(parent, txt, x, y, w, size, weight, color, align, lineH) {
  if (align === undefined) { align = "LEFT"; }
  if (lineH === undefined) { lineH = 1.05; }
  var fn = _fontFor(weight);
  await figma.loadFontAsync(fn);
  var t = figma.createText();
  t.fontName = fn;
  t.characters = txt;
  t.fontSize = size;
  t.textAlignHorizontal = align;
  t.fills = [{ type: "SOLID", color: col(color) }];
  t.lineHeight = { unit: "PERCENT", value: lineH * 100 };
  t.x = x; t.y = y;
  t.resize(w, t.height);
  parent.appendChild(t);
  return t;
}

async function buildSlide(data, offsetX) {
  var frame = figma.createFrame();
  frame.name = "Slide " + data.id + " - " + data.slideType;
  frame.resize(W, H);
  frame.x = offsetX; frame.y = 0;
  frame.fills = [{ type: "SOLID", color: col(data.bg) }];
  frame.clipsContent = true;

  for (var i = 0; i < 12; i++) {
    var line = figma.createLine();
    line.x = -100 + i * 110; line.y = 0;
    line.resize(H * 1.5, 0);
    line.rotation = -55;
    line.strokes = [{ type: "SOLID", color: col(data.accent), opacity: 0.04 }];
    line.strokeWeight = 40;
    frame.appendChild(line);
  }

  await addText(frame, "0" + data.id, 64, 60, 120, 13, "Bold", "WHITE");
  addRect(frame, 64, 85, 20, 2, data.accent);

  if (data.overline) {
    await addText(frame, data.overline, 64, 96, W - 128, 12, "Bold", "BROWN_L", "LEFT", 1.4);
  }

  if (data.pivotBar) { addRect(frame, 64, 148, 6, 260, data.accent); }

  var hX; if (data.pivotBar) { hX = 90; } else { hX = 64; }
  var hlColor; if (data.isCTA) { hlColor = "WHITE"; } else { hlColor = data.textColor; }
  await addText(frame, data.headline, hX, 148, W - hX - 40, 128, "Black Italic", hlColor, "LEFT", 0.92);

  var divY; if (data.isCTA) { divY = 740; } else { divY = 730; }
  addRect(frame, 64, divY, W - 128, 2, data.accent, 0.6);

  if (data.pills) {
    var pillX = 64;
    for (var j = 0; j < data.pills.length; j++) {
      var pill = data.pills[j];
      await figma.loadFontAsync({ family: "Arial", style: "Bold" });
      var pf = figma.createFrame();
      pf.resize(160, 36); pf.x = pillX; pf.y = divY + 20;
      pf.fills = [{ type: "SOLID", color: col("BROWN"), opacity: 0.25 }];
      pf.cornerRadius = 0;
      frame.appendChild(pf);
      var pt = figma.createText();
      pt.fontName = { family: "Arial", style: "Bold" };
      pt.characters = pill; pt.fontSize = 10;
      pt.textAlignHorizontal = "CENTER";
      pt.fills = [{ type: "SOLID", color: col("CREAM") }];
      pt.letterSpacing = { unit: "PERCENT", value: 20 };
      pt.resize(160, 36); pt.x = 0; pt.y = 12;
      pf.appendChild(pt);
      pillX += 172;
    }
  }

  if (data.subtext) {
    var subY; if (data.pills) { subY = divY + 70; } else { subY = divY + 24; }
    await addText(frame, data.subtext, 64, subY, W - 128, 22, "Regular", { r: 0.85, g: 0.80, b: 0.72 }, "LEFT", 1.6);
  }

  addRect(frame, 64, H - 96, W - 128, 1, "BROWN_L", 0.3);
  await addText(frame, "THE POWER COFFEE", 64, H - 78, 400, 11, "Bold", "BROWN_L", "LEFT", 1.4);
  await addText(frame, "CLEAN ENERGY. REAL FOCUS.", W - 380, H - 78, 316, 10, "Regular", { r: 0.6, g: 0.55, b: 0.48 }, "RIGHT", 1.4);

  if (data.isCTA) {
    addRect(frame, 0, H - 180, W, 180, "BROWN");
    await addText(frame, "POWER COFFEE", 64, H - 138, W - 128, 14, "Black", "WHITE", "LEFT", 1.2);
    await addText(frame, "thepowercoffee.com", 64, H - 110, W - 128, 13, "Regular", { r: 1, g: 0.95, b: 0.88 }, "LEFT", 1.4);
    await addText(frame, "@POWERCOFFEE.OFC", 64, H - 76, W - 128, 12, "Bold", "WHITE", "LEFT", 1.4);
  }

  figma.currentPage.appendChild(frame);
  return frame;
}

async function main() {
  var frames = [];
  for (var i = 0; i < SLIDES.length; i++) {
    var frame = await buildSlide(SLIDES[i], i * (W + GAP));
    frames.push(frame);
  }
  figma.viewport.scrollAndZoomIntoView(frames);
  figma.notify("Power Coffee - slides created!", { timeout: 4000 });
}

main();
