## The crash is not a character flaw

Every afternoon, somewhere around 2pm, the same thing happens. Your focus blurs. A simple task takes twice as long. You reach for another coffee, a snack, or you just push through and accept that the second half of the day is always the harder half.

Most people blame themselves. The schedule is too full. The sleep was too short. The discipline is not quite there.

The schedule is rarely the problem.

## What your morning coffee is actually doing

Standard caffeine — whether from drip coffee, espresso, or a pod — works by blocking adenosine receptors in the brain. Adenosine is the compound that builds up over the course of a day and signals tiredness. Caffeine blocks that signal temporarily.

The key word is temporarily.

When the caffeine clears, adenosine reasserts itself, often with more intensity than before. That is the crash. It is not weakness. It is chemistry. And it is baked into the design of caffeine consumed without any supporting ingredients.

## What a better afternoon actually requires

Sustained focus across a full day requires more than a stimulant. It requires ingredients that support how the body manages energy over time — not just in the first forty minutes after your morning cup.

That is the gap most coffee routines never fill.

## SCIENCE NOTE — Founder Interview Prep (not for publishing)
**Ingredient / mechanism:** Ginkgo Biloba Extract — flavonoid glycosides and terpene lactones acting on microvascular function and platelet-activating factor

Standardized Ginkgo biloba extract (typically 24% flavonoid glycosides, 6% terpene lactones — the form used in functional formulas and in most peer-reviewed trials) works through at least two complementary mechanisms relevant to cognitive performance. First, the terpene lactone fraction — specifically ginkgolides A, B, and C — acts as a selective antagonist of platelet-activating factor (PAF), a phospholipid mediator involved in platelet aggregation and inflammatory signaling in cerebral microvasculature. By inhibiting PAF binding at its receptor, ginkgolides support microvascular tone and blood rheology in small cerebral vessels. Second, the flavonoid fraction (quercetin, kaempferol, and isorhamnetin glycosides) exerts antioxidant activity at the mitochondrial and endothelial level, scavenging reactive oxygen species that impair nitric oxide bioavailability. The net effect studied in randomized trials is improved cerebral blood flow parameters and modest but measurable improvements in working memory speed and attention under cognitive load. Power Coffee contains 207mg of Ginkgo biloba extract per 10g serving.

**Reference:** Kaschel R. Specific memory effects of Ginkgo biloba extract EGb 761 in middle-aged healthy volunteers. Phytomedicine. 2011;18(14):1202-1207. [VERIFY CITATION — finding is well-established; confirm exact volume/page before citing on air]

**Interview angle:** The extract may support cerebral microvascular function through PAF antagonism, which could help explain observed improvements in working memory and attention speed in healthy adults under cognitive load — an effect worth distinguishing from simple stimulation.

function addRect(parent, x, y, w, h, color, opacity) {
  if (opacity === undefined) { opacity = 1; }
  var r = figma.createRectangle();
  r.x = x; r.y = y; r.resize(w, h);
  r.fills = [{ type: "SOLID", color: col(color), opacity: opacity }];
  parent.appendChild(r);
  return r;
}

// Font map — matches make_carousel.py (Pillow) rendering
// Headlines/body → Georgia | Labels/pills/footer → Arial
function _fontFor(weight) {
  if (weight === "Black Italic" || weight === "Bold Italic") { return { family: "Georgia", style: "Bold Italic" }; }
  if (weight === "Black" || weight === "Bold" && false)      { return { family: "Georgia", style: "Bold" }; }
  if (weight === "Italic" || weight === "Regular Italic")    { return { family: "Georgia", style: "Italic" }; }
  // Labels, overlines, pills, footer, counter use Arial
  if (weight === "Bold")    { return { family: "Arial", style: "Bold" }; }
  if (weight === "Regular") { return { family: "Georgia", style: "Regular" }; }
  return { family: "Arial", style: weight };
}

async function addText(parent, txt, x, y, w, size, weight, color, align, lineH) {
  if (align === undefined) { align = "LEFT"; }
  if (lineH === undefined) { lineH = 1.05; }
  var fn = _fontFor(weight);
  await figma.loadFontAsync(fn);
  var t = figma.createText();
  t.fontName = fn;
  t.characters = txt;
  t.fontSize = size;
  t.textAlignHorizontal = align;
  t.fills = [{ type: "SOLID", color: col(color) }];
  t.lineHeight = { unit: "PERCENT", value: lineH * 100 };
  t.x = x; t.y = y;
  t.resize(w, t.height);
  parent.appendChild(t);
  return t;
}

async function buildSlide(data, offsetX) {
  var frame = figma.createFrame();
  frame.name = "Slide " + data.id + " - " + data.slideType;
  frame.resize(W, H);
  frame.x = offsetX; frame.y = 0;
  frame.fills = [{ type: "SOLID", color: col(data.bg) }];
  frame.clipsContent = true;

  for (var i = 0; i < 12; i++) {
    var line = figma.createLine();
    line.x = -100 + i * 110; line.y = 0;
    line.resize(H * 1.5, 0);
    line.rotation = -55;
    line.strokes = [{ type: "SOLID", color: col(data.accent), opacity: 0.04 }];
    line.strokeWeight = 40;
    frame.appendChild(line);
  }

  await addText(frame, "0" + data.id, 64, 60, 120, 13, "Bold", "WHITE");
  addRect(frame, 64, 85, 20, 2, data.accent);

  if (data.overline) {
    await addText(frame, data.overline, 64, 96, W - 128, 12, "Bold", "BROWN_L", "LEFT", 1.4);
  }

  if (data.pivotBar) { addRect(frame, 64, 148, 6, 260, data.accent); }

  var hX; if (data.pivotBar) { hX = 90; } else { hX = 64; }
  var hlColor; if (data.isCTA) { hlColor = "WHITE"; } else { hlColor = data.textColor; }
  await addText(frame, data.headline, hX, 148, W - hX - 40, 128, "Black Italic", hlColor, "LEFT", 0.92);

  var divY; if (data.isCTA) { divY = 740; } else { divY = 730; }
