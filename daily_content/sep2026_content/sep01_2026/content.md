## SCIENCE NOTE — Founder Interview Prep (not for publishing)
**Ingredient / mechanism:** Ginkgo Biloba Extract — cerebral blood flow modulation and cognitive endurance under sustained task load

Ginkgo biloba extract (standardized to its characteristic flavonoid glycoside and terpene lactone content) is among the more extensively studied plant-derived nootropics for effects on cerebrovascular function. Its primary proposed mechanism involves modulation of cerebral blood flow via nitric oxide-mediated vasodilation and inhibition of platelet-activating factor, improving microcirculatory perfusion to cortical regions engaged during sustained attention tasks. A secondary mechanism involves antioxidant activity attributed to its flavonoid content, which may mitigate oxidative stress associated with prolonged cognitive load. Unlike caffeine's acute adenosine-receptor-mediated alertness effect, ginkgo's proposed benefit profile is more consistent with a longer time-course — supporting sustained cognitive performance across a working session rather than an immediate subjective lift. At the 207mg per-serving dose present in Power Coffee, this falls within ranges commonly studied in cognitive-performance literature, though effect sizes in existing research vary by population and outcome measure studied.

**Reference:** Kennedy DO, Scholey AB, Wesnes KA. "Modulation of cognitive performance following administration of single doses of Ginkgo biloba, ginseng, and a ginkgo/ginseng combination to healthy young adults." Physiology & Behavior, 2002;75(5):739-751. PMID: 12099998 [VERIFY citation and specific dose-response claims before publishing]

**Interview angle:** Ginkgo Biloba Extract may support the parts of the afternoon caffeine was never designed to reach — not a bigger lift, a longer one.

// ── HELPERS ──────────────────────────────────────────────────
function addRect(parent, x, y, w, h, color, opacity) {
  if (opacity === undefined) { opacity = 1; }
  var r = figma.createRectangle();
  r.x = x; r.y = y; r.resize(w, h);
  r.fills = [{ type: "SOLID", color: col(color), opacity: opacity }];
  parent.appendChild(r);
  return r;
}

// Font map — matches make_carousel.py (Pillow) rendering
// Headlines/body → Georgia | Labels/pills/footer → Arial
function _fontFor(weight) {
  if (weight === "Black Italic" || weight === "Bold Italic") { return { family: "Georgia", style: "Bold Italic" }; }
  if (weight === "Black" || weight === "Bold" && false)      { return { family: "Georgia", style: "Bold" }; }
  if (weight === "Italic" || weight === "Regular Italic")    { return { family: "Georgia", style: "Italic" }; }
  // Labels, overlines, pills, footer, counter use Arial
  if (weight === "Bold")    { return { family: "Arial", style: "Bold" }; }
  if (weight === "Regular") { return { family: "Georgia", style: "Regular" }; }
  return { family: "Arial", style: weight };
}

async function addText(parent, txt, x, y, w, size, weight, color, align, lineH) {
  if (align === undefined) { align = "LEFT"; }
  if (lineH === undefined) { lineH = 1.05; }
  var fn = _fontFor(weight);
  await figma.loadFontAsync(fn);
  var t = figma.createText();
  t.fontName = fn;
  t.characters = txt;
  t.fontSize = size;
  t.textAlignHorizontal = align;
  t.fills = [{ type: "SOLID", color: col(color) }];
  t.lineHeight = { unit: "PERCENT", value: lineH * 100 };
  t.x = x; t.y = y;
  t.resize(w, t.height);
  parent.appendChild(t);
  return t;
}

async function buildSlide(data, offsetX) {
