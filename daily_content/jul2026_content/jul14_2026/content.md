## What L-Theanine Actually Does

L-theanine is an amino acid found naturally in green tea leaves. On its own, it promotes a state of calm, alert focus — without sedation, without stimulation.

Its mechanism is distinct from caffeine's. Rather than blocking adenosine receptors (which is how caffeine creates alertness), L-theanine increases alpha brain wave activity. Alpha waves are associated with relaxed focus — the mental state you're in when you're doing your best thinking.

## Why the Ratio Is Everything

The research on caffeine + L-theanine is some of the most consistent in cognitive nutrition. A 2:1 ratio of L-theanine to caffeine has been shown in multiple studies to:

- Improve accuracy on sustained attention tasks
- Reduce the anxiety and jitteriness associated with caffeine alone
- Extend the focus window beyond what caffeine delivers independently

The problem: most coffee products either exclude L-theanine entirely, or include trace amounts that don't move the needle.

## How Power Coffee Delivers This

Power Coffee sources L-theanine through whole-leaf matcha — not an isolated extract. Matcha naturally contains both caffeine and L-theanine in close to the optimal ratio, which means the pairing is built into the ingredient itself.

Combined with ~175mg of caffeine from coffee and matcha, plus taurine, pea protein, and ginkgo biloba, Power Coffee is designed to deliver the full focus stack — not just the stimulant half of it.

function addRect(parent, x, y, w, h, color, opacity) {
  if (opacity === undefined) { opacity = 1; }
  var r = figma.createRectangle();
  r.x = x; r.y = y; r.resize(w, h);
  r.fills = [{ type: "SOLID", color: col(color), opacity: opacity }];
  parent.appendChild(r);
  return r;

// Font map — matches make_carousel.py (Pillow) rendering
// Headlines/body → Georgia | Labels/pills/footer → Arial
function _fontFor(weight) {
  if (weight === "Black Italic" || weight === "Bold Italic") { return { family: "Georgia", style: "Bold Italic" }; }
  if (weight === "Black" || weight === "Bold" && false)      { return { family: "Georgia", style: "Bold" }; }
  if (weight === "Italic" || weight === "Regular Italic")    { return { family: "Georgia", style: "Italic" }; }
  // Labels, overlines, pills, footer, counter use Arial
  if (weight === "Bold")    { return { family: "Arial", style: "Bold" }; }
  if (weight === "Regular") { return { family: "Georgia", style: "Regular" }; }
  return { family: "Arial", style: weight };
}

async function addText(parent, txt, x, y, w, size, weight, color, align, lineH) {
  if (align === undefined) { align = "LEFT"; }
  if (lineH === undefined) { lineH = 1.05; }
  var fn = _fontFor(weight);
  await figma.loadFontAsync(fn);
  var t = figma.createText();
  t.fontName = fn;
  t.characters = txt;
  t.fontSize = size;
  t.textAlignHorizontal = align;
  t.fills = [{ type: "SOLID", color: col(color) }];
  t.lineHeight = { unit: "PERCENT", value: lineH * 100 };
  t.x = x; t.y = y;
  t.resize(w, t.height);
  parent.appendChild(t);
  return t;
}
