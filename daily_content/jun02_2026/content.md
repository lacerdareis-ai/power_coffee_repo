<h2>The Ingredient Most Functional Coffees Get Wrong</h2>

<p>Ginger appears in wellness formulas constantly — usually in trace amounts, included as a nod to tradition rather than a dose that does actual work. Power Coffee takes a different approach. Every serving contains 440mg of ginger, and the reasoning comes down to one word: mechanism.</p>

<h2>What the Active Compounds Do</h2>

<p>Ginger's primary active compounds are gingerols and shogaols. These inhibit prostaglandin synthesis — the same biochemical pathway targeted by anti-inflammatory medications. The difference is that ginger delivers this effect without synthetic compounds, at a level your system tolerates daily without adaptation concerns.</p>

<p>Research on exercise-induced inflammation has associated consistent ginger intake with reduced delayed-onset muscle soreness (DOMS) and lower levels of inflammatory markers including C-reactive protein (CRP) and interleukin-6 (IL-6). The effect is cumulative, not acute — which is why daily use matters more than a single high dose.</p>

<h2>Why It Matters for Morning Performance</h2>

<p>If you train in the morning, your system is already managing inflammatory load before the workday begins. Your regular coffee adds a cortisol response to that equation. Ginger, at 440mg per serving, supports the counter-response — helping the system settle rather than amplify.</p>

<p>Ginger also supports gastric motility, the rate at which your stomach empties. If coffee on an empty stomach has ever felt harsh, that is partly gut inflammation — and ginger directly addresses the mechanism.</p>

<h2>5,000 Years Before the Research</h2>

<p>Ginger has been documented in traditional medicine for over 5,000 years — in Ayurvedic texts, ancient Chinese herbalism, and the Greek pharmacopoeia. Modern sports science is providing the mechanism that explains what practitioners observed empirically for millennia. We did not put ginger in Power Coffee because it is trending. We put it there because the evidence points in the same direction from every angle.</p>

function addRect(parent, x, y, w, h, color, opacity) {
  if (opacity === undefined) { opacity = 1; }
  var r = figma.createRectangle();
  r.x = x; r.y = y; r.resize(w, h);
  r.fills = [{ type: "SOLID", color: col(color), opacity: opacity }];
  parent.appendChild(r);
  return r;
}

async function addText(parent, txt, x, y, w, size, weight, color, align, lineH) {
  if (align === undefined) { align = "LEFT"; }
  if (lineH === undefined) { lineH = 1.05; }
  await figma.loadFontAsync({ family: "Inter", style: weight });
  var t = figma.createText();
  t.fontName = { family: "Inter", style: weight };
  t.characters = txt;
  t.fontSize = size;
  t.textAlignHorizontal = align;
  t.fills = [{ type: "SOLID", color: col(color) }];
  t.lineHeight = { unit: "PERCENT", value: lineH * 100 };
  t.x = x; t.y = y;
  t.resize(w, t.height);
  parent.appendChild(t);
  return t;
}

async function buildSlide(data, offsetX) {
