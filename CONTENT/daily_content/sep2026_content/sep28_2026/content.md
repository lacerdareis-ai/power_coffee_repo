A reviewer once asked me why I put "basically what's in Red Bull" into my own coffee.

Fair question. I have gotten it more than once.

Here is what I told them: taurine is not the ingredient people assume it is. It is not a stimulant. The research on it is fairly specific — it functions as a neuromodulator, meaning its role is to help regulate the nervous system's response to stimulation, not add to it.

So when I formulated Power Coffee, I did not avoid it. I used more of it — 2.1g per serving, versus roughly 1g in a standard energy drink can. And I left out the 27g of sugar that usually comes along with it.

Most "clean energy" positioning skips the actual chemistry and goes straight to vibes. I would rather show the dose and let people check it themselves.

## SCIENCE NOTE — Founder Interview Prep (not for publishing)
**Ingredient / mechanism:** Natural Caffeine — adenosine receptor antagonism and the cortisol interaction window

Caffeine exerts its stimulant effect primarily by competing with adenosine at A1 and A2A receptors in the brain. Adenosine is a byproduct of neuronal activity that accumulates across the waking day; when it binds its receptors it progressively suppresses arousal and alertness. Caffeine blocks this binding without activating the receptor, effectively removing the brake on dopaminergic and noradrenergic signaling and restoring a sense of alert wakefulness.

The clinically relevant complication is timing. Caffeine consumed in the morning coincides with the cortisol awakening response, which peaks roughly 30 to 45 minutes after waking. Adding a strong caffeine stimulus on top of that peak may amplify downstream cortisol elevation and contributes to the rebound fatigue and mood dip users describe hours later when both caffeine clearance and cortisol decline happen in proximity.

At approximately 175mg per serving, Power Coffee sits within the EFSA-established single-dose threshold of 200mg associated with no safety concerns for healthy adults, while remaining sufficient for meaningful receptor occupancy and alertness support.

**Reference:** Nehlig A, Daval JL, Debry G. "Caffeine and the central nervous system: mechanisms of action, biochemical, metabolic and psychostimulant effects." Brain Research Reviews, 1992. [VERIFY CITATION for exact volume/page]

**Interview angle:** Caffeine does not create energy — it removes the signal that tells your brain to slow down, which is a meaningful distinction when you are thinking about why the second cup eventually stops working.

// ── HELPERS ──────────────────────────────────────────────────
function addRect(parent, x, y, w, h, color, opacity) {
  if (opacity === undefined) { opacity = 1; }
  var r = figma.createRectangle();
  r.x = x; r.y = y; r.resize(w, h);
  r.fills = [{ type: "SOLID", color: col(color), opacity: opacity }];
  parent.appendChild(r);
  return r;
}

// Font map — matches make_carousel.py (Pillow) rendering
// Headlines/body → Georgia | Labels/pills/footer → Arial
function _fontFor(weight) {
  if (weight === "Black Italic" || weight === "Bold Italic") { return { family: "Georgia", style: "Bold Italic" }; }
  if (weight === "Black" || weight === "Bold" && false)      { return { family: "Georgia", style: "Bold" }; }
  if (weight === "Italic" || weight === "Regular Italic")    { return { family: "Georgia", style: "Italic" }; }
  // Labels, overlines, pills, footer, counter use Arial
  if (weight === "Bold")    { return { family: "Arial", style: "Bold" }; }
  if (weight === "Regular") { return { family: "Georgia", style: "Regular" }; }
  return { family: "Arial", style: weight };
}

async function addText(parent, txt, x, y, w, size, weight, color, align, lineH) {
  if (align === undefined) { align = "LEFT"; }
  if (lineH === undefined) { lineH = 1.05; }
  var fn = _fontFor(weight);
  await figma.loadFontAsync(fn);
  var t = figma.createText();
  t.fontName = fn;
  t.characters = txt;
  t.fontSize = size;
  t.textAlignHorizontal = align;
  t.fills = [{ type: "SOLID", color: col(color) }];
  t.lineHeight = { unit: "PERCENT", value: lineH * 100 };
  t.x = x; t.y = y;
  t.resize(w, t.height);
  parent.appendChild(t);
  return t;
}

async function buildSlide(data, offsetX) {
  var frame = figma.createFrame();
  frame.name = "Slide " + data.id + " - " + data.slideType;
  frame.resize(W, H);

  frame.clipsContent = true;

  if (data.subtext) {
    var subY; if (data.pills) { subY = divY + 70; } else { subY = divY + 24; }
