## The Real Reason You Crash at 2pm

It is not that you are tired. It is not that you need a fourth cup. It is that your coffee was designed to do one thing and stop.

Caffeine works by blocking adenosine receptors — the receptors your brain uses to register fatigue. For roughly ninety minutes, it holds. Then the block clears. Every unit of tiredness you postponed lands at once.

That is the crash. And it is entirely predictable from the formula.

The question is not how to avoid caffeine. The question is what you add alongside it to extend and smooth the window.

## Taurine: The Amino Acid Nobody Talks About

Taurine is found in almost every commercial energy drink, and almost nobody knows why.

It is not a stimulant. It does not spike anything. What it does is work alongside an activated nervous system to smooth overstimulation and support sustained output. Two grams — a full dose — is what research consistently points to. Most standard coffee products contain none.

## Matcha: The Slow Burn Your Morning Needs

Matcha contains its own caffeine, but it behaves differently.

L-theanine, a compound present in matcha, modulates how caffeine is processed — shifting the experience from a sharp spike toward calm, extended alertness. People who add matcha describe the same thing: longer focus, less edge, no hard wall at the end.

Combined with your regular brew, it stretches the energy curve rather than doubling the peak.

## Ginkgo Biloba: When the Thinking Gets Hard

Ginkgo biloba has been studied for its role in supporting circulation, including to the brain.

The practical effect is clarity that holds when the morning gets demanding. Not a buzz. Not a tingle. Just the work feeling more accessible two hours in than it did at the start.

## SCIENCE NOTE — Founder Interview Prep (not for publishing)
**Ingredient / mechanism:** Taurine — GABAergic modulation and calcium homeostasis under caffeine load

Taurine (2-aminoethanesulfonic acid) is a conditionally essential amino acid present in high concentrations in excitable tissues — the heart, skeletal muscle, and central nervous system. Its primary role in the context of stimulant co-administration is not additive stimulation but neuromodulatory balance. Taurine acts as a partial agonist at GABA-A receptors and glycine receptors, which are inhibitory ion channels; this activity contributes to a damping effect on excessive neuronal excitation — the physiological signature of caffeine-driven overstimulation. Additionally, taurine functions as an intracellular osmolyte and assists in regulating mitochondrial membrane potential and calcium ion flux, both of which are disrupted under oxidative stress conditions associated with high caffeine intake. At a dose of 2g — within the range used in peer-reviewed human trials — taurine has been associated with improved time-to-exhaustion and reduced markers of oxidative stress during sustained effort.

**Reference:** Waldron M, et al. "The Effects of an Acute Taurine Ingestion on Endurance Performance and Metabolism in Well-Trained Cyclists." International Journal of Sport Nutrition and Exercise Metabolism, 2018. [VERIFY CITATION — findings are established; confirm exact volume/page]

**Interview angle:** Taurine does not add stimulation — it may help the nervous system sustain output under the load that caffeine creates, which is a meaningfully different mechanism than anything caffeine does on its own.

function addRect(parent, x, y, w, h, color, opacity) {
  if (opacity === undefined) { opacity = 1; }
  var r = figma.createRectangle();
  r.x = x; r.y = y; r.resize(w, h);
  r.fills = [{ type: "SOLID", color: col(color), opacity: opacity }];
  parent.appendChild(r);
  return r;
}

// Font map — matches make_carousel.py (Pillow) rendering
// Headlines/body → Georgia | Labels/pills/footer → Arial
function _fontFor(weight) {
  if (weight === "Black Italic" || weight === "Bold Italic") { return { family: "Georgia", style: "Bold Italic" }; }
  if (weight === "Black" || weight === "Bold" && false)      { return { family: "Georgia", style: "Bold" }; }
  if (weight === "Italic" || weight === "Regular Italic")    { return { family: "Georgia", style: "Italic" }; }
  // Labels, overlines, pills, footer, counter use Arial
  if (weight === "Bold")    { return { family: "Arial", style: "Bold" }; }
  if (weight === "Regular") { return { family: "Georgia", style: "Regular" }; }
  return { family: "Arial", style: weight };
}

async function addText(parent, txt, x, y, w, size, weight, color, align, lineH) {
  if (align === undefined) { align = "LEFT"; }
  if (lineH === undefined) { lineH = 1.05; }
  var fn = _fontFor(weight);
  await figma.loadFontAsync(fn);
  var t = figma.createText();
  t.fontName = fn;
  t.characters = txt;
  t.fontSize = size;
  t.textAlignHorizontal = align;
  t.fills = [{ type: "SOLID", color: col(color) }];
  t.lineHeight = { unit: "PERCENT", value: lineH * 100 };
  t.x = x; t.y = y;
  t.resize(w, t.height);
  parent.appendChild(t);
  return t;
}
