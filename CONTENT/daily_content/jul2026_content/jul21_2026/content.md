### Body

## What Is L-Theanine?

L-Theanine is an amino acid found naturally in green tea leaves. Unlike most compounds in the supplement world, it has a well-established body of research behind it — and a mechanism that's unusually well understood.

It crosses the blood-brain barrier and increases alpha brain wave activity. Alpha waves are associated with a state of calm, alert focus — the mental mode you're in when you're in flow, not when you're anxious or asleep.

## The Problem With Caffeine Alone

Caffeine works by blocking adenosine receptors — the receptors that signal tiredness to your brain. That's why it wakes you up. But caffeine also triggers a cortisol spike.

Cortisol is a stress hormone. In short bursts, it's useful. Sustained, it narrows your thinking, increases anxiety, and sets up the crash that hits mid-afternoon — usually right when you need focus most.

## What L-Theanine Actually Does to the Equation

When paired with caffeine, L-Theanine doesn't reduce energy. It shapes it.

A 2008 study published in *Nutritional Neuroscience* tested 100mg of L-Theanine combined with 50mg of caffeine against caffeine alone. The combination produced significantly better performance on attention-switching tasks and improved accuracy under pressure — with fewer reports of headache and fatigue.

The L-Theanine blunted the cortisol spike. The caffeine provided the drive. Together, they produced something neither could alone: sustained, calm energy.

## Why Most Coffees Skip It

L-Theanine doesn't make coffee taste different. It doesn't make a good marketing headline on its own. So most brands skip it entirely.

Every scoop of Power Coffee pairs L-Theanine with matcha-sourced caffeine — a naturally slower-releasing caffeine form — so the energy window extends to 4-6 hours instead of the typical 45-minute spike-and-crash.

function addRect(parent, x, y, w, h, color, opacity) {
  if (opacity === undefined) { opacity = 1; }
  var r = figma.createRectangle();
  r.x = x; r.y = y; r.resize(w, h);
  r.fills = [{ type: "SOLID", color: col(color), opacity: opacity }];
  parent.appendChild(r);
  return r;
}

// Font map — matches make_carousel.py (Pillow) rendering
// Headlines/body → Georgia | Labels/pills/footer → Arial
function _fontFor(weight) {
  if (weight === "Black Italic" || weight === "Bold Italic") { return { family: "Georgia", style: "Bold Italic" }; }
  if (weight === "Black" || weight === "Bold" && false)      { return { family: "Georgia", style: "Bold" }; }
  if (weight === "Italic" || weight === "Regular Italic")    { return { family: "Georgia", style: "Italic" }; }
  // Labels, overlines, pills, footer, counter use Arial
  if (weight === "Bold")    { return { family: "Arial", style: "Bold" }; }
  if (weight === "Regular") { return { family: "Georgia", style: "Regular" }; }
  return { family: "Arial", style: weight };
}

async function addText(parent, txt, x, y, w, size, weight, color, align, lineH) {
  if (align === undefined) { align = "LEFT"; }
  if (lineH === undefined) { lineH = 1.05; }
  var fn = _fontFor(weight);
  await figma.loadFontAsync(fn);
  var t = figma.createText();
  t.fontName = fn;
  t.characters = txt;
  t.fontSize = size;
  t.textAlignHorizontal = align;
  t.fills = [{ type: "SOLID", color: col(color) }];
  t.lineHeight = { unit: "PERCENT", value: lineH * 100 };
  t.x = x; t.y = y;
  t.resize(w, t.height);
  parent.appendChild(t);
  return t;
}
