## LINKEDIN
### Post
I fired someone at 4:47pm on a Thursday. The time was the mistake.

I didn't choose 4:47pm on purpose. That was just when the conversation finally happened — I'd been putting it off all day, and it caught up with me late.

I've since learned that late afternoon is close to the worst possible window for a conversation like that. Not because of willpower. Because of a receptor.

Here's the mechanism, and it's not complicated: your brain runs on a molecule called adenosine that builds up the longer you've been awake — it's the actual chemical signal behind feeling tired, foggy, short-fused. Caffeine doesn't remove that buildup. It blocks the receptor that reads it, for roughly as long as the caffeine stays in your system — about five hours, on average.

So if your last real coffee was late morning, the block is wearing off right around late afternoon. The adenosine was never gone. It was just muted. By 4:47pm, it's back, in full, exactly when a hard conversation needs you at your most controlled — not your most depleted.

I'd scheduled the hardest decision of that week for the worst possible hour of my own day, and I didn't know it, because nobody schedules around a receptor. We schedule around calendars.

This isn't a caffeine pitch. It's an operator pitch: the thing you're protecting when you manage your energy isn't your energy. It's the quality of the decisions you make with it. A founder who's sharp at 10am and running on fumes at 4pm isn't one person all day — they're two different decision-makers, and most of us let the calendar pick which one handles the hard stuff.

I changed one thing after that Thursday: anything consequential — a hard conversation, a pricing call, a hire or a fire — gets scheduled against my own curve now, not just against open calendar slots. Sometimes that means earlier. Sometimes it means a second, smaller dose of something steady later in the day instead of pushing through on willpower alone. The mechanism doesn't care which — it just means knowing where you actually are on it before you schedule something that matters.

Most performance advice tells you to manage your time. The actual lever is managing when on your own curve the important decisions land.

— Leo, building Power Coffee one real decision at a time.

## SCIENCE NOTE — Founder Interview Prep (not for publishing)
**Ingredient / mechanism:** Natural Caffeine (~175mg per 10g serving) as an adenosine receptor antagonist
Caffeine's primary acute mechanism is competitive antagonism at adenosine A1 and A2A receptors in the central nervous system. Adenosine accumulates throughout waking hours as a byproduct of cellular ATP metabolism, binding A1/A2A receptors to promote neuronal inhibition and the subjective sense of sleepiness. Caffeine structurally resembles adenosine closely enough to occupy these receptor sites without activating them, blocking adenosine's inhibitory signal. This disinhibits dopaminergic and glutamatergic signaling downstream, which is why alertness rises without a direct stimulant action of its own. EFSA's safety opinion anchors single-dose intake at or below 200mg as not raising acute safety concerns for most healthy adults, which is why a 175mg serving sits deliberately under that threshold rather than near it. The "crash" people describe is partly receptor rebound: once caffeine clears, accumulated adenosine binds in a wave, which is a separate phenomenon from blood sugar swings but often gets confused with them.
**Reference:** Fredholm BB, et al. "Actions of caffeine in the brain with special reference to factors that contribute to its widespread use." Pharmacological Reviews, 1999;51(1):83-133. PMID: 10049999
**Interview angle:** Caffeine doesn't create energy, it blocks the signal that tells your brain you're tired — which is why dose and timing matter more than most people assume, and why we kept this serving at a level designed to support alertness without pushing past established single-dose guidance.

// ── HELPERS ──────────────────────────────────────────────────
function addRect(parent, x, y, w, h, color, opacity) {
  if (opacity === undefined) { opacity = 1; }
  var r = figma.createRectangle();
  r.x = x; r.y = y; r.resize(w, h);
  r.fills = [{ type: "SOLID", color: col(color), opacity: opacity }];
  parent.appendChild(r);
  return r;
}

// Font map — matches make_carousel.py (Pillow) rendering
// Headlines/body → Georgia | Labels/pills/footer → Arial
function _fontFor(weight) {
  if (weight === "Black Italic" || weight === "Bold Italic") { return { family: "Georgia", style: "Bold Italic" }; }
  if (weight === "Black" || weight === "Bold" && false)      { return { family: "Georgia", style: "Bold" }; }
  if (weight === "Italic" || weight === "Regular Italic")    { return { family: "Georgia", style: "Italic" }; }
  // Labels, overlines, pills, footer, counter use Arial
  if (weight === "Bold")    { return { family: "Arial", style: "Bold" }; }
  if (weight === "Regular") { return { family: "Georgia", style: "Regular" }; }
  return { family: "Arial", style: weight };
}

async function addText(parent, txt, x, y, w, size, weight, color, align, lineH) {
  if (align === undefined) { align = "LEFT"; }
  if (lineH === undefined) { lineH = 1.05; }
  var fn = _fontFor(weight);
  await figma.loadFontAsync(fn);
  var t = figma.createText();
  t.fontName = fn;
  t.characters = txt;
  t.fontSize = size;
  t.textAlignHorizontal = align;
  t.fills = [{ type: "SOLID", color: col(color) }];
  t.lineHeight = { unit: "PERCENT", value: lineH * 100 };
  t.x = x; t.y = y;
  t.resize(w, t.height);
  parent.appendChild(t);
  return t;
}

async function buildSlide(data, offsetX) {
  var frame = figma.createFrame();
  frame.name = "Slide " + data.id + " - " + data.slideType;
  frame.resize(W, H);
  frame.x = offsetX; frame.y = 0;
  frame.fills = [{ type: "SOLID", color: col(data.bg) }];
  frame.clipsContent = true;

  for (var i = 0; i < 12; i++) {
    var line = figma.createLine();
    line.x = -100 + i * 110; line.y = 0;
    line.resize(H * 1.5, 0);
    line.rotation = -55;
    line.strokes = [{ type: "SOLID", color: col(data.accent), opacity: 0.04 }];
    line.strokeWeight = 40;
    frame.appendChild(line);
  }

  await addText(frame, "0" + data.id, 64, 60, 120, 13, "Bold", "WHITE");
  addRect(frame, 64, 85, 20, 2, data.accent);

  if (data.overline) {
    await addText(frame, data.overline, 64, 96, W - 128, 12, "Bold", "BROWN_L", "LEFT", 1.4);
  }

  if (data.pivotBar) { addRect(frame, 64, 148, 6, 260, data.accent); }

  var hX; if (data.pivotBar) { hX = 90; } else { hX = 64; }
  var hlColor; if (data.isCTA) { hlColor = "WHITE"; } else { hlColor = data.textColor; }
  await addText(frame, data.headline, hX, 148, W - hX - 40, 128, "Black Italic", hlColor, "LEFT", 0.92);

  var divY; if (data.isCTA) { divY = 740; } else { divY = 730; }
  addRect(frame, 64, divY, W - 128, 2, data.accent, 0.6);

  if (data.pills) {
    var pillX = 64;
    for (var j = 0; j < data.pills.length; j++) {
      var pill = data.pills[j];
      await figma.loadFontAsync({ family: "Arial", style: "Bold" });
      var pf = figma.createFrame();
      pf.resize(160, 36); pf.x = pillX; pf.y = divY + 20;
      pf.fills = [{ type: "SOLID", color: col("BROWN"), opacity: 0.25 }];
      pf.cornerRadius = 0;
      frame.appendChild(pf);
      var pt = figma.createText();
      pt.fontName = { family: "Arial", style: "Bold" };
      pt.characters = pill; pt.fontSize = 10;
      pt.textAlignHorizontal = "CENTER";
      pt.fills = [{ type: "SOLID", color: col("CREAM") }];
      pt.letterSpacing = { unit: "PERCENT", value: 20 };
      pt.resize(160, 36); pt.x = 0; pt.y = 12;
      pf.appendChild(pt);
      pillX += 172;
    }
  }

  if (data.subtext) {
    var subY; if (data.pills) { subY = divY + 70; } else { subY = divY + 24; }
    await addText(frame, data.subtext, 64, subY, W - 128, 22, "Regular", { r: 0.85, g: 0.80, b: 0.72 }, "LEFT", 1.6);
  }

  addRect(frame, 64, H - 96, W - 128, 1, "BROWN_L", 0.3);
  await addText(frame, "THE POWER COFFEE", 64, H - 78, 400, 11, "Bold", "BROWN_L", "LEFT", 1.4);
  await addText(frame, "CLEAN ENERGY. REAL FOCUS.", W - 380, H - 78, 316, 10, "Regular", { r: 0.6, g: 0.55, b: 0.48 }, "RIGHT", 1.4);

  if (data.isCTA) {
    addRect(frame, 0, H - 180, W, 180, "BROWN");
    await addText(frame, "POWER COFFEE", 64, H - 138, W - 128, 14, "Black", "WHITE", "LEFT", 1.2);
    await addText(frame, "thepowercoffee.com", 64, H - 110, W - 128, 13, "Regular", { r: 1, g: 0.95, b: 0.88 }, "LEFT", 1.4);
    await addText(frame, "@POWERCOFFEE.OFC", 64, H - 76, W - 128, 12, "Bold", "WHITE", "LEFT", 1.4);
  }

  figma.currentPage.appendChild(frame);
  return frame;
}

async function main() {
  var frames = [];
  for (var i = 0; i < SLIDES.length; i++) {
    var frame = await buildSlide(SLIDES[i], i * (W + GAP));
    frames.push(frame);
  }
  figma.viewport.scrollAndZoomIntoView(frames);
  figma.notify("Power Coffee - slides created!", { timeout: 4000 });
}

main();
