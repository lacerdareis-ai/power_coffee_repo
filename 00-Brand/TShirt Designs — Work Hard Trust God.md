# T-Shirt Designs — "Work Hard, Trust God"

**5 layout variants · Black t-shirt · Mascot logo**

---

## How to run

1. Open Figma → a file in The Power Coffee workspace
2. Go to **Plugins → Scripter**
3. Paste or open the script below and click **Run**
4. After the frames appear, **replace each mascot placeholder** with the actual image:
   - File: `Sales_motor/daily_content/_brand_kit/cutouts/mascot_logo.png`
   - In Figma: select the placeholder → right-click → **Fill with image**

**Script location:**
`Sales_motor/daily_content/_brand_kit/figma_tshirt_designs.js`
