## Contingency Plans

### If Shopify conversion < 2%
- **Root cause:** Copy/avatar mismatch
- **Response:** A/B test hero, CTA, copy variation within 2 weeks
- **Escalation:** Bring in copywriter if in-house iteration doesn't move needle

### If Amazon ACoS > 40%
- **Root cause:** Bid too high or keywords mismatched
- **Response:** Pause bottom 30% performers, reallocate to winners
- **Escalation:** Reduce daily budget, focus on Tier 1 keywords only

### If retail can't land first store
- **Root cause:** Timing (should be month 4+), positioning, or sample quality
- **Response:** Extend DTC phase, improve sample presentation, adjust pitch
- **Escalation:** Bring in retail consultant for strategy adjustment
