## Key Learnings

- Vanilla removal validated: taste test confirmed no flavor loss — lean into cleaner 11-ingredient story
- Mocha SKU economics: Dutch Cocoa swap saves ~$272/batch; theobromine requires pet safety labeling
- Event sampling: small-format tastings (3 oz), minimal table clutter, one clear CTA (QR + discount)
- Editorial/press: iterative revision style works well — short specific corrections applied directly
- Figma Scripter: all `figma.loadFontAsync()` calls must fully resolve before text node creation; coordinates must fall within frame bounds
