## Ingredient Stack — Full Reference

> Doses marked ✅ are confirmed from brand documentation.
> Doses marked 🔬 are research-backed recommendations from the formulation consultation (2026-06-16).
> Doses marked ❓ are unconfirmed — verify against physical label.

### 1. Instant Coffee ☕
| Field | Value |
|---|---|
| **Dose** | ~1.5g (1,500mg) 🔬 |
| **Caffeine yield** | ~40–55mg per serving |
| **Role** | Base energy + ritual familiarity |
| **Mechanism** | Adenosine receptor antagonist — blocks sleep pressure signals temporarily |
| **Key fact** | Caffeine half-life is ~5 hours. At 10am your caffeine is still active. What crashes isn't the caffeine — it's blood sugar. |

---

### 2. Matcha Green Tea 🍵
| Field | Value |
|---|---|
| **Dose** | 600mg 🔬 |
| **Caffeine yield** | ~12–15mg additional caffeine |
| **L-theanine from matcha** | ~9–12mg natural L-theanine |
| **Role** | Sustained energy, smooth arc |
| **Mechanism** | Caffeine bound to L-theanine in the leaf — slows absorption, extends hold, reduces spike |
| **Science hook** | "Energy over 4–6 hours, not 45 minutes" |
| **Key fact** | Matcha's caffeine is structurally the same as coffee caffeine but the binding to L-theanine changes the release curve. |

---

### 3. L-Theanine 🧠
| Field | Value |
|---|---|
| **Dose** | 200mg 🔬 |
| **Total L-theanine per serving** | ~210mg (200mg supplemental + ~10mg from matcha) |
| **Role** | Alert calm — focus without restlessness |
| **Mechanism** | Increases alpha brain wave activity; modulates GABA and glutamate; enhances caffeine's cognitive benefits while blunting jitter response |
| **Science hook** | "The reason matcha feels different from coffee is L-theanine. We add it separately so the dose is consistent, not batch-dependent." |
| **Research** | Haskell et al., 2008: L-theanine + caffeine improved attention-switching speed and accuracy vs caffeine alone → [[Formula-Research#L-Theanine + Caffeine]] |

---

### 4. Taurine ⚡
| Field | Value |
|---|---|
| **Dose** | **2,000mg (2g) ✅** |
| **Role** | Clean focus, neuromodulation |
| **Mechanism** | Modulates GABA receptors, regulates neuronal excitability. NOT a stimulant — prevents overstimulation from caffeine |
| **Science hook** | "Taurine is in Red Bull — but not for the reason you think. It doesn't stimulate. It stops the stimulants from going too far." |
| **Differentiator** | **2,000mg = double what Red Bull puts in a can (1,000mg).** This is a competitive claim worth owning. |
| **Research** | Ripps & Shen, 2012 → [[Formula-Research#Taurine]] |

## Formula Philosophy

> "The brands charging $35 aren't putting more inside the scoop. They're paying for the influencer who posted it and the agency that positioned it. I have neither. So the savings go into the price."

The formula was built around three problems most functional coffees don't solve simultaneously:
1. **The caffeine crash** — addressed by matcha + L-theanine smoothing the arc
2. **The blood sugar crash** — addressed by pea protein + cinnamon holding the glucose floor
3. **Overstimulation** — addressed by taurine modulating neuronal excitability

The result is not more energy. It's more consistent energy. The floor holds.
